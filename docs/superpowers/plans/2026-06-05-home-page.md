# jonathon.dev Home Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a single-page, dark warm-themed portfolio home page with a breathing ember "jonathon.dev" hero, a projects grid, an experience timeline, skills, and contact links.

**Architecture:** App Router page composing small, single-purpose section components. All editable content lives in one typed module (`lib/content.ts`). Theme is dark-only via warm OKLCH tokens in `app/globals.css`. The only animation is a CSS keyframe "breath" on the hero glow, gated by `prefers-reduced-motion`.

**Tech Stack:** Next.js 16.2.6 (App Router), React 19, Tailwind CSS v4, shadcn scaffolding, fonts Oxanium/Inter/Geist Mono (already wired in `app/layout.tsx`).

**Verification note:** No unit-test runner is installed and none is added (YAGNI for a static visual page). Each task is verified with `npm run lint`, `npm run build`, and — where visual — a Playwright browser check against `npm run dev`. The `playwright-cli` skill / Playwright MCP is available.

**Next.js 16 caveat:** Per `AGENTS.md`, before writing framework code read the relevant guide under `node_modules/next/dist/docs/01-app/`. Font API (`next/font/google` with `variable`) and `export const metadata` are confirmed unchanged in this version.
